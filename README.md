# Requisition System

A standalone, browser-based prototype for the school board requisition workflow.

## Open it

Double-click `index.html` to open the system in a web browser. No installation, server, or account is required.

## Included workflow

1. Staff submit a requisition with items and an estimated total.
2. A Coordinator can approve it for Finance or record a rejection reason.
3. Finance approval, inventory availability, purchasing, and release are visible in the request status.
4. The dashboard and report page provide quick operational summaries.

Requests submitted in the prototype are stored only in that browser on that device. This is a functional interface prototype, not a shared production database.
